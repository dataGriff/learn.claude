# Exercises

Short hands-on tasks to cement the concepts in `docs/`. Each one should take 5-15 minutes.

| #   | Exercise                                    | Concept              |
| --- | ------------------------------------------- | -------------------- |
| 00  | [Write a slash command](00-write-a-command.md) | `docs/04-slash-commands.md` |
| 01  | [Tighten permissions](01-tighten-permissions.md) | `docs/03-permissions.md` |
| 02  | [Add a guardrail hook](02-add-a-hook.md)         | `docs/07-hooks.md`        |
| 03  | [Build a skill](03-build-a-skill.md)             | `docs/05-skills.md`       |

Work through them in order if you're new to Claude Code. Each exercise is self-contained — your changes go in `.claude/` and stay local unless you commit them.

## Working an exercise

Open the exercise file. It has three sections:

- **Goal** — what you'll have built when you're done.
- **Steps** — a short list of things to do, in order.
- **Acceptance** — how to know it works.

Solutions aren't checked in. The point is to read the relevant doc, then build the artifact yourself. If you get stuck, ask Claude — these exercises are designed to be solvable in-session.
